# AVESON ARTIST

Public-facing Android application for artists in the AVESON ecosystem.

## Technology
- Java
- XML layouts
- Android Gradle Plugin 8.6.1
- Minimum SDK: 24
- Compile / Target SDK: 35

## Package
`com.aveson.artist`

## Project structure
- `app/src/main/java/com/aveson/artist/` — Android application source
- `auth/` — future authentication module
- `profile/` — future artist profile module
- `releases/` — future release submission and management module
- `media/` — future audio and cover-art handling
- `network/` — future API client and server communication
- `security/` — future session and security utilities
- `core/` — shared application components

The module folders are placeholders for planned work. No backend connection, authentication, upload, or release workflow is implemented yet.

## Build
Open this folder in Android Studio and allow Gradle sync. Use JDK 17.
